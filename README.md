# Lexify

Toshkent davlat yuridik universiteti uchun jonli dars va kurs platformasi.

Mahalliy: http://localhost:3000

Bu loyiha **Open Tsul** (`https://open.okina.uz`) emas. U saytga deploy qilinmaydi.

## Tez boshlash

```bash
cp .env.example .env
npm install
npm run db:migrate
npm run db:seed    # faqat development
npm run dev
```
